## Sign-In Architecture

Preferred onboarding:

1. Visit GDEX.pro.

2. Select the supported sign-in or wallet connection method.

3. Use Web3Auth where appropriate for simplified onboarding.

4. Connect or create the user's self-custodial wallet environment.

5. Verify the selected blockchain before conducting any transaction.

6. Enter the relevant Market Lab.

## Chain Routing

The Market Lab does not pretend every asset exists on every chain.

Instead, each transaction receives an explicit chain designation.

Examples:

$DUMP
→ Solana

$DLAB / DELL Market Lab
→ Robinhood Chain / Pons infrastructure as applicable

GLend
→ Arbitrum

ENOCH ONE perpetual copytrade
→ Use the network and collateral requirements specified by GDEX for the selected product.

## Routing Principle

GDEX is the front door.

The actual blockchain is the settlement rail.

The student should always know which chain is being used before signing a transaction.
